# おのみち部活さがし（Google サイト × スプレッドシート）

> **運用を引き継ぐ方へ：まず [HANDOVER.md](HANDOVER.md)（引き継ぎ資料）を読んでください。**

尾道市の中学生向けに、学校外のクラブ・教室・体験イベントをスマホで見やすく一覧できるページのサンプルです。
**データはスプレッドシート1枚**で管理し、ページはそれを読んで自動で表示します。

```
apps-script/Code.gs     … スプレッドシートを読んで返す（Apps Script）
apps-script/index.html  … 表示画面（スマホ向けカードUI）
preview.html            … 同じ画面をサンプルデータで動かすプレビュー用
sample-data.csv         … シートの列構成のテンプレート
```

## スプレッドシートの列（1行目の見出し）

| 列 | 内容 | 例 |
|---|---|---|
| 公開 | チェックボックス。外すとサイトに出ない | ☑ |
| 種別 | `クラブ` / `イベント` | クラブ |
| 種目 | 自由入力（同じ表記に揃えるとチップがまとまる） | バスケットボール |
| 名称 | 団体名・イベント名 | 尾道シーサイド・バスケットクラブ U15 |
| 参加対象 | `男子・女子` / `男子` / `女子` | 男子・女子 |
| 対象学年 | 自由入力 | 中1〜中3 |
| 費用 | 自由入力（文字のまま表示） | 月3,000円 |
| 活動日 | クラブは頻度、イベントは日時 | 週2日（火・木 19:00〜21:00） |
| 活動場所 | | 長江中学校 体育館 |
| 校区 | 最寄りの中学校名。`全域` は全校区に表示 | 長江中学校 |
| 紹介 | 「くわしく見る」を開くと出る文章 | |
| 連絡先 | | 担当：山本（070-…） |
| URL | あるとボタンが出る | https://… |
| URLパスワード | 入れると、その行の URL はパスワードを入れた人にだけ表示される。空欄なら誰でも見られる | onomichi2026 |

| 問い合わせ先メール | サイトのフォームから届く問い合わせ・申し込みの送り先。空欄ならフォームを出さない | club@example.com |

列の名前を変えたい場合は `index.html` の `COL` と `Code.gs` の `HEADERS` を合わせて変更してください。

### URLパスワードについて

パスワードの判定は Apps Script（サーバー側）で行い、**ロックされた行の URL はブラウザに送られません**。
画面側で隠すだけでは開発者ツールから読めてしまうため、`getClubs()` が URL を落とし、
`getUrl(row, password)` が正しいパスワードを受け取ったときだけ URL を返します。

既に運用中のシートに後から列を足す場合は、Apps Script エディタで `addMissingColumns()` を1回実行してください（`HEADERS` にあってシートに無い列をまとめて右端に足します）。

この仕組みは「パスワードを知らない人に URL を見せない」ためのものです。
パスワードを知った人が URL を他人に転送することは防げません。本当に秘密にすべきものには使わないでください。

CSV 公開方式（下記「代替」）ではパスワードを確かめるサーバーが無いため、この機能は使えません。

## セットアップ手順（おすすめ：Apps Script 方式）

シートを公開設定にしなくてよく、管理者はシートを編集するだけで反映されます。

1. Google スプレッドシートを新規作成
2. メニュー「拡張機能」→「Apps Script」
3. 既定の `コード.gs` の中身を `apps-script/Code.gs` の内容に置き換える
4. 「＋」→「HTML」で `index` という名前のファイルを作り、`apps-script/index.html` の内容を貼り付ける
5. エディタ上部で `setupSheet` を選んで「実行」（初回は権限の承認あり）
   → 「クラブ一覧」シートに見出し・サンプル行・プルダウンが作られます
6. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示された URL をスマホで開いて動作確認
8. Google サイトの編集画面 → 「挿入」→「Apps Script」→ 上のプロジェクトを選ぶ
   - 埋め込み枠の高さは 900〜1200px くらいにすると見やすいです（枠の中でスクロールします）

以後は **シートを編集するだけ** で反映されます（ページ再読み込みで最新化）。
`index.html` を直したときだけ「デプロイを管理」→ 新バージョンとして更新してください。

## 引き継ぎ資料（`apps-script/Handover.gs`）

運用の引き継ぎ資料を、スプレッドシートの中に「引き継ぎ」シートとして作ります。
システムと一緒に移動するので、ファイルを渡せば資料も付いてきます。

```
setupHandoverSheet()   # 「引き継ぎ」シートを作る（先頭タブに配置）
```

既に「引き継ぎ」シートがある場合は、`引き継ぎ（旧 日付）` に名前を変えて残し、新しく作り直します。
シートを直接編集して構いません。内容の元は `HANDOVER.md` と同じです。

### 画像URLについて

`imageUrl_()` が、貼られた値を `<img src>` に使える形へ直します。

- Google ドライブの共有リンク（`/file/d/<id>/view`、`open?id=`、`uc?id=`）→ `https://drive.google.com/thumbnail?id=<id>&sz=w1200`
- ファイルIDだけ → 同上
- 外部サイトの `http(s)` URL → そのまま
- それ以外（`javascript:`、`data:`、URLでない文字）→ 空文字（画面に渡さない）

ドライブの共有リンクをそのまま `<img src>` にしても表示されません。あれはページを開くURLで、画像そのものではないためです。
**この変換は Google 側の仕様に依存します。** ドライブのファイルは「リンクを知っている全員」に共有されている必要があり、
将来 Google がサムネイル配信を変えると表示されなくなる可能性があります。その場合は外部ホスティングに切り替えてください。

画像が読み込めなかった場合は、枠ごと DOM から外して余白が残らないようにしています（`error` は伝播しないので capture で拾う）。

## 問い合わせ・申し込みフォーム（`apps-script/Contact.gs`）

カードの「くわしく見る」の中にフォームを出し、その団体の「問い合わせ先メール」宛に送ります。
**試用中は2パターンを同時に出し、どちらが良いか比べられるようにしています。**

| | 出るボタン | 用途 |
| --- | --- | --- |
| パターン1（1・3・5…番目の団体） | ボタンなし。「くわしく見る」を開くとフォームが直接出る | 質問も申し込みもここに含める |
| パターン2（2・4・6…番目の団体） | 「問い合わせる」＋「見学・体験を申し込む」の2ボタンから開く | 質問と、具体的な行動を分ける |

割り当ては `getClubs()` の `_form`（シート上の並び順の偶奇）で決まります。
パターン1はできることが1つしかないため、ボタンを挟まずフォームをそのまま置いています。
決まったら、片方だけを出すように `contactButtons()` を直し、`SHOW_PATTERN_LABEL` を `false` にしてください。

### 設計の要点

- **団体のメールアドレスはブラウザに送りません。** `getClubs()` が `問い合わせ先メール` を落とし、
  `_canContact`（真偽値）だけを渡します。宛先は `submitContact()` がシートから引き直すので、
  送信先を外から指定することはできません。
- 全送信を「問い合わせ履歴」シートに記録します。メールが失敗しても記録は残ります。
- 連絡先がメールアドレスの形なら `replyTo` に入れるので、団体はそのまま返信できます。
  電話番号など、形が違うものは入れません。

### 濫用対策

| 対策 | 内容 |
| --- | --- |
| 罠フィールド | 画面に出ない入力欄。埋まっていたら、成功したように見せて送信しない |
| 最短入力時間 | フォームを開いてから3秒未満の送信を拒否 |
| 送信上限 | 1団体あたり5件／時、全体で30件／時（`CacheService` で計数、`LockService` で重複防止） |
| 入力長の上限 | 名前100字・連絡先200字・内容2000字。制御文字は除去 |

`CONTACT.ccOperator`（既定 `true`）で、運用者にも控えが届きます。試用中は届いているか確認できるので `true` のままを推奨します。

## 自動の見張り（`apps-script/Health.gs`）

毎日1回、以下を確認して異常があればメールで知らせます。

1. シートが読め、必要な見出しが揃っているか
2. `getClubs()` が例外なく1件以上返すか
3. パスワード付きの行の URL が外に漏れていないか
4. デプロイ済みのページが外から見て動いているか（`?health=1` を叩き、`{ok, count}` を確認）

4 は `doGet` の `?health=1` を使います。Apps Script のウェブアプリを取得しても
返るのはサンドボックスの外枠だけで、画面の中身は後から JavaScript で差し込まれるため、
HTML に目印を探す方法では確かめられません。件数だけを返す軽い出口を叩いて、
デプロイ済みのコードが実際にシートを読めているかを確認します（団体の情報は返しません）。

通知先は、スプレッドシートの「通知先」シート（`有効` / `メールアドレス` / `担当・備考`）で管理します。
1行1アドレスで何件でも登録でき、チェックを外した行には送りません。
シートが空なら `HEALTH.notifyTo`、それも空ならスクリプトの持ち主に送るので、通知が完全に止まることはありません。

状態が変わったときだけ送るので、正常な間はメールが来ません（週次の「異常なし」レポートは除く）。
見張り自体が止まった場合は、その週次レポートが途絶えることで気づけます。

```
setupHealthCheck()   # 1回だけ実行。「通知先」シートを作り、毎日8時台のトリガーを仕掛ける
testHealthCheck()    # 手動で1回確認し、結果を必ずメールする
removeHealthCheck()  # 止める
```

初回実行時に UrlFetchApp・MailApp・トリガー作成の権限承認が必要です。
`HEALTH.webAppUrl` は、デプロイし直して URL が変わったら書き換えてください。

## 代替：Apps Script を使わない方式（埋め込みコード）

1. シートを「ファイル」→「共有」→「ウェブに公開」→ 形式「CSV」で公開し、URL をコピー
2. `apps-script/index.html` の `CONFIG.csvUrl` にその URL を入れる
3. Google サイト →「挿入」→「埋め込む」→「埋め込みコード」に index.html の中身を貼る

シートが誰でも読める状態になる点と、Google サイト側の埋め込みコードが長くなる点に注意してください。

## 見た目の調整

`index.html` の先頭 `:root { … }` に色をまとめています。
`--accent`（メインの青）と `--event`（イベントの橙）を変えると全体の色が変わります。
フォントは BIZ UDPGothic（本文・UDフォント）と Zen Maru Gothic（見出し）を Google Fonts から読み込んでいます。
